# Notebook Guide

This folder contains the exploratory notebook for the anomaly detection project.

Use the notebook to:

- load the dataset
- inspect the schema
- check missing values
- understand distribution and class balance
- perform EDA
- benchmark the five anomaly models
- compare performance metrics

Open the notebook in Jupyter:

```bash
cd /home/indranil/Desktop/Real-time-Anomaly-Detection-Pipeline
source .venv/bin/activate
jupyter notebook notebooks/anomaly_detection_eda.ipynb
```
