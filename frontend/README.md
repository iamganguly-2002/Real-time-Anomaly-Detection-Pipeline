# Frontend Demo

This frontend is a lightweight UI for the anomaly detection API.

## Run the frontend

Open the file directly in a browser or serve it with Python:

```bash
cd /home/indranil/Desktop/Real-time-Anomaly-Detection-Pipeline/frontend
python3 -m http.server 8080
```

Then open:

```text
http://127.0.0.1:8080
```

Make sure the backend is running on port 8001 or update the fetch URL in the script if needed.
